# Demos de sistemas

Prototipos em HTML estatico, um por pasta. Cada pasta e um projeto na Vercel.

- atendimento-reforco/: atendimento IA + reforco escolar
- erp-rotas-frota/: ERP com OS, rotas, contratos e frota
- erp-refrigeracao/: ERP para refrigeracao e climatizacao (rota do dia com GPS, app do tecnico, orcamentos, lembretes, notas fiscais, estoque, metas da equipe)
- lava-jato/: Auto Brilho, lava-jato a domicilio (painel + pagina de reserva em #reservar)
